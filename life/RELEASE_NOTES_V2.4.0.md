# JustGlance v2.4.0 — Editability, Space Hub, Shopping Navigation

- Added a dedicated top-level Shopping experience across Spaces.
- Reframed Spaces as membership/permission containers: invite once to the whole Space, then control category access.
- Added editable Space names and editable/archivable shopping-list names.
- Added project name/description/status/priority/target editing.
- Added appointment editing/deletion from Planner.
- Added thought/note editing/deletion.
- Added saved-place editing/deletion.
- Preserved existing item and contact editing.
- Removed Shopping items from the Tasks command center.
- Added Space-scoped views for Tasks, Planner, Projects, Thoughts and Shopping.
- Reorganized desktop navigation into Today, Do, Remember, and People & sharing groups.
- Mobile navigation remains intentionally stable; Shopping is available from More.
- Bundled the corrected Chrome extension v1.0.1 and updated Settings to download it.
- No database migration is required for this release when the current master schema repair has already been applied.
- Enforced category permissions in the UI: view-only members no longer see edit/complete/archive controls for shared items, projects, appointments, or thoughts they cannot change.
