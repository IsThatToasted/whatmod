# WeTrack V3.1.2 — Card Restructure + Overflow Audit

## V2 itinerary cards
- Replaces the crowded action button strip with one settings cog.
- Settings popover contains Edit, -30, +30, Rain Plan, Lock/Unlock and Delete.
- Preserves the existing underlying event handlers and permissions.
- Mobile agenda cards use a simple two-column Time + Event layout.
- Address and Apple/Google map buttons share one clean row.
- Map actions remain compact icons.
- 30-minute cards use the same geometry as longer cards.
- Drag grip and tap-to-expand remain intact.

## Dashboard/mobile overflow
- Planned Budget, Travel Expense, Total Expense and other metric cards are reflowed.
- Currency values receive the full card width and use responsive type sizing.
- Added V2 mobile overflow guards for Trip Details, editor fields and content surfaces.

No Supabase changes.
