Brian M. Chambers Portfolio

DEPLOYMENT
1. Copy this entire "portfolio" folder into the root of your whatmod GitHub repository.
2. Commit and push.
3. Your page should be available at:
   https://whatmod.com/portfolio/

EASY EDITING
Most portfolio project content is inside app.js under:
   const projects = [ ... ]

Edit name/summary/contact wording directly in index.html.

SCREENSHOTS
1. Create a folder named assets inside /portfolio/.
2. Put project screenshots there, for example:
   assets/wetrack.png
3. In app.js, change the project's image field from:
   image: ""
   to:
   image: "assets/wetrack.png"

CONTACT
Replace every occurrence of:
   your@email.com
with your actual email address.

GITHUB
The current GitHub link points to:
   https://github.com/whatmod
Change it in index.html if needed.
